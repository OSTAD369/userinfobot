# userinfobot
ربات یوزر اینفو | User Info Bot یک ابزار حرفه‌ای تلگرام برای بررسی و تحلیل اطلاعات کاربران، پیام‌ها، گروه‌ها و کانال‌هاست. توسعه‌یافته با Python، همراه با قابلیت استخراج آیدی، تحلیل پیام‌های فورواردی، دریافت اطلاعات پروفایل، گزارش‌گیری و خروجی JSON. ساخته‌شده با افتخار توسط OSTAD369 🚀
