# userinfobot
ربات یوزر اینفو | User Info Bot یک ابزار حرفه‌ای تلگرام برای بررسی و تحلیل اطلاعات کاربران، پیام‌ها، گروه‌ها و کانال‌هاست. توسعه‌یافته با Python، همراه با قابلیت استخراج آیدی، تحلیل پیام‌های فورواردی، دریافت اطلاعات پروفایل، گزارش‌گیری و خروجی JSON. ساخته‌شده با افتخار توسط OSTAD369 🚀
🚀 **USER INFO BOT | ربات یوزر اینفو**
### ابزار تخصصی بررسی و تحلیل اطلاعات تلگرام
**طراحی و توسعه: OSTAD369**

🔥 وقتی صحبت از بررسی اطلاعات کاربران و پیام‌های تلگرام باشد، نام **ربات یوزر اینفو (User Info Bot)** به میان می‌آید!

امروز می‌خواهم یکی از پروژه‌های اختصاصی خودم را معرفی کنم؛ ابزاری که با زبان برنامه‌نویسی Python توسعه داده‌ام و مجموعه‌ای از قابلیت‌های کاربردی برای بررسی اطلاعات کاربران، پیام‌ها، گروه‌ها و کانال‌های تلگرام را در یک ربات یکپارچه ارائه می‌کند.

**ربات یوزر اینفو** با هدف ارائه اطلاعات دقیق، دسترسی آسان به جزئیات پیام‌ها و فراهم‌کردن ابزارهای تحلیلی در محیط تلگرام ساخته شده است.

### ⚡ امکانات و قابلیت‌های ربات یوزر اینفو

👤 **اطلاعات کاربران**
- دریافت اطلاعات و مشخصات قابل‌دسترسی کاربران
- استخراج شناسه عددی (User ID)
- بررسی اطلاعات نویسنده پیام‌ها
- دریافت تصاویر پروفایل کاربران

💬 **تحلیل پیام‌ها**
- بررسی جزئیات پیام‌های تلگرام
- تحلیل پیام‌های فورواردشده
- شناسایی فرستنده پیام‌های پاسخ‌داده‌شده
- بررسی انواع مختلف پیام‌ها و محتوای آن‌ها
- استخراج شناسه فایل‌ها (File ID و File Unique ID)

📢 **اطلاعات گروه‌ها و کانال‌ها**
- دریافت شناسه گروه و کانال
- بررسی مشخصات و اطلاعات قابل‌دسترسی چت‌ها
- نمایش اطلاعات عضویت و دسترسی‌های مدیریتی در موارد قابل‌دسترسی

📊 **گزارش‌گیری و امکانات پیشرفته**
- خروجی اطلاعات در قالب JSON
- تولید گزارش HTML
- ذخیره‌سازی سوابق در پایگاه داده SQLite
- تاریخچه بررسی‌ها و آمار ربات
- منوهای تعاملی و دکمه‌های اختصاصی
- پنل مدیریت و ابزارهای مدیریتی
- پشتیبانی از تاریخ شمسی و میلادی
